# 知己 Windows 客户端

面向不使用 CLI、Skill 或 Agent 的普通用户。本客户端不在运行时调用 Claude Skill 或 Agent；Electron Main Process 以严格 Schema 和确定性排版实现同一套用户可见契约，避免模型自由改变报告结构。

## Skill Runtime 边界

- 当前仅支持 Windows 本地单用户；只在应用打开时运行，不启动后台常驻服务。
- 日反馈使用版本化兼容快照与 LangGraph JS 编排，不会动态执行 Skill Markdown。
- 桌面端不读取、执行或修改 Codex + `.claude` Skill 系统；原系统可继续独立用于开发和日常使用。
- 桌面端数据目录会追加 `runtime/daily-feedback-audit.jsonl` 审计摘要，用于追溯日反馈等级、结果和昨日行动状态；其中不保存 API Key 或日记全文。

日反馈当前的支持范围与延后项见 [Skill 兼容矩阵](docs/skill-compatibility-matrix.md)。

## 当前 MVP

- 五个入口：开始、日志、复盘、项目、设置。开始页只给一个基于本地数据确定性计算的建议动作，另有做复盘、查看记录、管理项目三个低权重入口。
- 本地 Markdown/JSON 保存日志、复盘、项目和个人背景；默认数据目录为 Windows“文档/知己”，侧栏与设置均显示真实路径，设置可直接打开文件夹。
- 用户自己的 OpenAI 兼容 API Key；Key 仅由 Electron Main Process 使用，并通过 Windows `safeStorage` 加密。连接测试通过后会同步安全保存配置并刷新全局 AI 状态。
- 支持日反馈、周报、月报、项目复盘；日反馈按 Skill 契约呈现昨日闭环、一个有原文支撑的盲点、可选历史连接、一个五分钟原子行动、可观察预测和认知追踪。日志可选择今天或过去日期并关联项目，同日可保存多条且互不覆盖，周期复盘可补选日期范围并在生成前预览材料。
- 复盘页默认只突出周/月/项目；按需展开“更多洞察”后可做日志质量检查、年度回顾和快速方向校准。日志质量检查逐篇呈现 A-D 分析就绪度、六步法证据、重复模式和一项优先改进；三者都先预览材料再生成，并进入同一历史与删除链路。
- 日反馈和复盘正文仍以 Markdown 保存在本地，界面会安全渲染标题、引用、列表和表格，不显示 `#` 等排版符号，也不执行日志中的 HTML。
- 日志历史归在日志页，可从任意历史日志直接生成对应日期的日反馈；全部复盘历史归在复盘页，从项目发起复盘时自动带入所选项目。
- 日志和复盘可逐条移到 Windows 回收站且不会级联删除来源；项目名全局唯一，支持重命名、归档和恢复，只有无关联日志的项目可移到回收站。
- 设置可移除当前服务商保存的 API Key；原生下拉控件保持系统行为，并统一了尺寸、圆角、箭头和聚焦反馈。
- 个人背景固定保存在 `<数据目录>/profile/about-me.md`，可在设置中查看、编辑、启停和清空；不会自动生成画像，只有用户开启“允许 AI 使用”后才会注入复盘和方向校准。
- 设置页支持带 SHA-256 清单和业务 Schema 校验的 `.zhiji.zip` 备份与空目录恢复；导出日志、复盘、项目、个人背景和公开配置，不包含 API Key 或缓存。
- Renderer 禁用 Node 集成并启用上下文隔离和沙箱；文件、密钥和网络仅通过具名 IPC 访问。

## 开发验证

```powershell
npm test
npm run typecheck
npm run package
npm run test:e2e
npm start
```

`npm run test:e2e` 会先自动生成 Electron 构建入口，再启动隔离测试窗口；不要直接用 Electron 打开源码目录。

依赖和缓存可放在 D 盘，项目中的 `node_modules` 可使用 Windows Junction 指向 D 盘目录。

## 当前发布边界

发布校验覆盖自动化测试、TypeScript、Lint（0 error）、真实 Electron E2E 和 Windows x64 打包。测试覆盖同日多日志、历史补写与日反馈、DeepSeek JSON 输出兼容、Skill 日反馈结构、日志质量契约、安全 Markdown 展示、个人资料授权、深度分析材料门槛、安全回收站删除、项目唯一命名与完整生命周期、AI Key 清除、并发冲突、周期复盘预览与备份完整性；不会写入真实用户数据。

发布前人工理解测试（3–5 位不使用 CLI 的目标用户，每项先观察 10 秒，不提示路径）：

1. 请开始写一篇日志。
2. 请指出写完后如何生成今日反馈。
3. 请找到本周复盘入口。
4. 请指出个人资料与日志存在哪里，以及如何导入、导出。

记录每项首次点击是否正确及卡住原因；这一测试未完成前，不把自动化通过等同于真实用户觉得简单。
